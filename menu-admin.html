Cobros y kiosco

Flujo de pago del menú

El modo kiosco cobra en Clover antes de enviar el pedido a Cocina. Está preparado para una pantalla Android con Kiosk Browser y conexión HTTPS a Supabase.

Estado del servicio de pago Sin comprobar
Asignación de pantallas a Clover Flex

Cada pantalla Android usa un kiosk_id y la función busca el número de serie del Flex correspondiente.

kiosk-01 → Flex principal kiosk-02 → Flex secundario
La tabla se administra en Supabase: clover_kiosk_devices. El ZIP incluye el SQL y ejemplos.
